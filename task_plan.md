## Key Questions
1. Which fixed dimensions actually overflow below 480px?
2. Which desktop tables need cards versus safe horizontal scrolling?
3. Which two/three-panel pages need mobile state switching?

## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Preserve desktop composition at xl and introduce mobile-specific task hierarchy below xl | Prevents squeezing desktop UI into narrow screens |
| Prefer vertical stacking and full-width primary actions on mobile | Avoids one-character text columns and improves touch usability |
| Use horizontal scroll only for dense data tables where card conversion would hide comparison context | Maintains access to all columns without page-level overflow |
